Watch it come up:

  kubectl -n {{ .Release.Namespace }} port-forward svc/{{ include "b2c-api.fullname" . }} 3001:{{ .Values.service.port }}{{ if .Values.metrics.enabled }} {{ .Values.metrics.port }}:{{ .Values.metrics.port }}{{ end }}

Point the web app at it, so its demo links call this release:

  helm upgrade b2c-web ./helm/b2c-web -n {{ .Release.Namespace }} \
    --set demoApiUrl=http://{{ include "b2c-api.fullname" . }}:{{ .Values.service.port }}/hello
